# 獅子獣録

VTuber・配信者向けの予定表作成＆紹介文管理ツールです。白を基調にした業務ツール風の画面で、PCとスマホの両方から利用できます。

**ビルド不要・ログイン不要。HTML / CSS / JavaScriptの静的ファイルだけで動きます。** 外部のライブラリ、CDN、アクセス解析は使用していません。

## GitHub Pagesで公開する

1. 納品ZIPを展開します。
2. `shishijuroku`フォルダの**中身**をGitHubリポジトリのルートにアップロードします。`index.html`がリポジトリの一番上にある状態にしてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を **Deploy from a branch** にします。
5. **Branch** を `main`、フォルダを **/(root)** にして **Save** を押します。
6. 公開処理が終わったら、Pagesに表示される **Visit site** から開きます。

通常の公開URLは `https://あなたのユーザー名.github.io/リポジトリ名/` です。すべての参照を相対パスにしているため、リポジトリ名を変えてもコードの修正は不要です。`.nojekyll`も同梱しています。ビルドコマンドや環境変数の設定はありません。

公開設定の詳細は[GitHub公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)を参照してください。今回の納品では、GitHubへのアップロード・実際の公開は行っていません。

## 機能

### 予定表

- 月曜日始まりの週間予定表（1600 × 1000 px）
- 月間予定表（1600 × 1320 px）。月末・年越し・うるう年・6行になる月に対応
- 時間、タイトル、カテゴリ、配信先、メモ。1日4件まで
- 予定表のタイトル、配信者名、ひとことを編集
- PNG出力、拡大プレビュー、テキストの告知文コピー
- 期間ごとに独立した下書きを自動保存（最大500期間）

最初の週は編集用のサンプルを表示します。編集するか、予定パネルの「サンプルを消す」から空にしてください。

### 12種類のテンプレート

リネン / スカイ / ブルーム / ミント / ライラック / エディトリアル / サニー / ノートブック / ピクセル / スタジオ / キャンディ / オーシャン。

週間予定表はカード・縦列・リストの3系統。月間予定表は月曜始まりのカレンダー形式です。背景の模様や配色も異なります。アクセント・背景・カード・文字の4色を自由に変更できます。

### 画像・テキスト

- PNG / JPEG / WebP / GIFのアップロード（1枚12MBまで）
- ドラッグ移動、右下ハンドルでサイズ変更
- 横・縦位置、サイズ、回転、透明度の数値・スライダー操作
- 重なり順、複製、削除。最大30アイテム
- テキストと6種類のワンポイントラベル
- 選択中のアイテムは矢印キーで移動。Shift併用で大きく移動

画像は透明部分を保った静止PNGとして取り込みます。長辺1800pxを目安に縮小し、非常に大きいデータはさらに縮小します。GIFは静止画になります。自動的な背景除去はありません。元のファイルは変更しません。

### 配信者・紹介文

名前、YouTube・Xのリンク、管理用メモを登録します（最大1000人）。紹介する人を選び、「すべて」「YouTubeのみ」「Xのみ」を切り替えてコピーできます。メモは紹介文に含めません。

標準の文章:

```text
■{name}様
　・YouTube: {youtube_link}
　・X: {x_link}
```

リンク未登録・出力対象外のプレースホルダーを含む行は丸ごと省かれます。各リンクは別の行に置いてください。文章テンプレートは編集・保存でき、複数人の文章は空行で区切ります。

YouTubeのみ登録した人の例:

```text
■配信者名様
　・YouTube: https://www.youtube.com/@your-channel
```

名前だけの登録もできます。YouTubeリンクはYouTubeドメイン、XリンクはX・TwitterドメインのHTTPS URLを受け付けます。コピーAPIが使えないブラウザでは、選択済みテキストから手動でコピーできる画面を表示します。

### 保存・履歴・バックアップ

- 編集内容をIndexedDBに自動保存
- 「履歴に保存」で予定表を最大50件保存（51件目で最も古い履歴を除く）
- 履歴の再編集とPNG出力
- 履歴を開くときは、異なる既存下書きも履歴に退避
- 全データをJSONでダウンロード・復元
- 復元前のデータは自動でJSONに書き出す
- 不正な形式のJSON、リンク、埋め込みIDを検証して拒否
- 読み取れない保存データは上書きせず保護し、バックアップから救出可能

スマホのバックアップは、画面下の **使い方・保存 → バックアップを開く** から利用できます。

## データについて

登録情報・画像は利用中のブラウザ内に保存され、サーバーへ送信しません。端末・ブラウザ・公開URLが変わると別の保存場所になります。端末間の自動同期・アカウント・共有編集はありません。PCからスマホへ移す際はJSONバックアップを使ってください。同時編集は1つのタブで行ってください。

ブラウザデータの削除、プライベートモードの終了、保存容量不足などで保存内容を失う可能性があります。**定期的にバックアップをダウンロードしてください。** 保存エラーは画面上に表示します。

復元できるJSONは100MB以下です。画像を多数含むデータは大きくなるため、画像を適度なサイズにし、不要な履歴を整理してください。

長い文字は画像の枠内で省略します。週間のメモ・カテゴリ・配信先はレイアウトと件数に応じて表示し、月間は日付・時間・タイトルを中心に表示します。全文は予定編集画面や告知文から確認できます。配色や画像の重なりは、書き出し前にプレビューで確認してください。

## ローカルで確認する

Pythonが利用できる場合、展開した`shishijuroku`フォルダで次を実行してください。

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

ブラウザで `http://localhost:8080/` を開きます。HTMLの直接起動はブラウザによって保存・コピーの制約が異なるため、ローカルサーバーまたはGitHub Pagesでの利用を推奨します。

## 構成

```text
shishijuroku/
  index.html
  styles.css
  app.js
  model.js
  renderer.js
  storage.js
  assets/
    favicon.svg
    favicon.ico
    favicon-32.png
    apple-touch-icon.png
  readme.md
  CODEX_PROGRESS.md
  .nojekyll
```

ファビコンは獅子の顔を描いたSVGと16/32/48px入りICOを同梱しています。Apple touch iconは180pxです。

## 確認済みの範囲

2026年10月9日、ローカルHTTPサーバーのリポジトリ配下URLで確認:

- Chromeの独立したテストブラウザで、予定編集・再読み込み後の自動保存・期間別下書き
- 12テンプレートの週間・月間描画、6行の月、1日4件
- 透明PNGの取り込み・移動・サイズ・回転・透明度・重なり順・複製・テキスト
- 週間PNGとプレビューのピクセル一致、週・月の画像サイズ
- 履歴保存・復元時の下書き退避
- 配信者登録、任意リンク、文章置換、リンク別出力、コピー操作の呼び出し
- JSON出力・復元と不正データ拒否
- 1440pxのPC幅、390pxのタッチ端末エミュレーションでの操作と横はみ出し
- 日付境界・年越し・うるう年・リンクとバックアップの検証
- 320px幅の画面とテンプレート選択、保存エラーの通知、読み取れない元データの保護・救出・復元

クリップボードへの書き込みはテスト用の受け取り先に差し替えて検証しました。実際の端末のクリップボード、iOS Safari実機、GitHub Pagesでの公開後の動作はまだ未確認です。
